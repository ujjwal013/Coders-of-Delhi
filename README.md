# Data Cleaning & Preprocessing with JSON

A Python-based data cleaning and preprocessing project focused on working with structured JSON datasets containing user profiles, friendship relationships, and liked pages.

The project demonstrates practical data-cleaning techniques such as handling missing values, identifying duplicate records, detecting inconsistent data, and preparing raw JSON data for reliable analysis.

## Key Features

- Load and process JSON datasets using Python
- Identify missing and incomplete user information
- Detect duplicate records and repeated relationships
- Handle inconsistent page and user data
- Clean and transform raw JSON data
- Generate cleaned datasets for further analysis
- Work with small and large JSON datasets

## Technologies Used

- Python
- Jupyter Notebook
- JSON
- Data Cleaning & Preprocessing

## Project Structure

- `intro(COD)1.ipynb` — Introduction and initial data processing
- `data_cleaning(COD)2.ipynb` — Data cleaning operations
- `People_U_may_no3.ipynb` — User/social-network data processing
- JSON files — Raw and cleaned datasets used throughout the project

## Objective

The main objective of this project is to understand and implement practical data-cleaning workflows on semi-structured JSON data before using it for analysis or downstream data-processing tasks.
